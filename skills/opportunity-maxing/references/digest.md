# The digest email

One email per hunt run, only when something needs the user. Send it with the Gmail connector to the address in `Setup → Digest email`, and only to that address. If there is no Gmail access, put the same content in the chat reply instead.

Subject: `Opportunity Maxing: {N} new, {M} deadlines this week` (drop a part that is zero).

Body (HTML, short, readable on a phone), sections in this order and skipped when empty:

1. **Act this week**: tracked rows whose deadline is within 7 days or whose start-prep date has passed. Name, deadline (home time zone), what is still missing, link to the Plan doc.
2. **New for you**: new Strong and Possible rows, Strong first, then by deadline. Name, type, deadline, funding in five words, one-line why, official link. At most 10; then "and {N} more in the tracker".
3. **Changed**: deadlines moved, closed early, eligibility changed.
4. **Questions**: anything the user should answer, e.g. "Did you apply to OPP-004? Set Status to Applied." or "Profile §11 referees are TBC; 3 of your Strong matches need them."
5. One line: link to the tracker and "Type Y in Track? for anything you want to go for."

No attachments. No marketing tone. No emojis unless the user's Setup asks.
